ModelWorkspace

class ModelWorkspace

Immutable exact-id workspace produced from a finite or provider-collected source set. Construction admits and freezes every supplied source; prepare resolves only the requested entry's transitive closure.

snapshotRevision is sanitized provenance captured from a collection provider. It is null for finite fromSources workspaces and never contributes to a prepared-model fingerprint.
