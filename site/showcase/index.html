How to use this page

  1. Start with a built-in example

    Choose a demo Document, then select Validate or Compute. The matching model workspace and Document are already loaded; no download or upload is required.

  2. Use your own files

    Use Load workspace folder for a directory of related models, or Choose model files to select them individually. Then choose the entry model. Load Document replaces the editable JSON input.

  3. Choose how the workspace is read

    Finite file map prepares all selected model sources together. On-demand provider requests only the models discovered through includes and imported typedefs.

  4. Prepare, validate, or compute

    Prepare workspace resolves the selected model and shows its dependencies. Validate and Compute prepare automatically when the model selection has changed. Runs repeats validation or computation against the same prepared interpreter and Document; one run reports elapsed time and multiple runs report p95.

  5. Choose the validation scope

    Full document validates the complete Document. Relevant scenario group validates only the group and coordinates shown beside the operation buttons. Results and failures appear as structured JSON.

  6. Local file handling

    Nothing is uploaded. The page reads selected models and Documents locally in the browser and does not store user-selected files in its offline cache.
