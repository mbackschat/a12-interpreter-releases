How to use this page

  1. Start with a built-in example

    Choose a demo Document, then select Validate or Compute. The matching model workspace and Document are already loaded; no download or upload is required.

  2. Use your own files

    Use Load workspace folder for a directory of related models, or Choose model files to select them individually. Then choose the entry model. Preparing a different model replaces stale demo input with a model-shaped starter; Use model-shaped starter regenerates it explicitly. Load Document replaces the editable JSON input.

  3. Choose how the workspace is read

    Finite file map prepares all selected model sources together. On-demand provider requests only the models discovered through includes and imported typedefs.

  4. Prepare, validate, or compute

    Prepare workspace resolves the selected model and shows its dependencies. Check model support reports admitted rules, computations, and custom-typed field declarations that the configured interpreter cannot evaluate without reading the Document; every entry is a model element. Validation and computation report unsupported entries too, and those may additionally name a single Document cell — each entry’s subject says which. Validate checks the current Document as-is; each computation has an implicit consistency rule, so a stale filled target appears as a validation finding. Compute retains a result without changing the Document, Apply results writes those exact actions into the editable Document, and Compute → Apply → Validate runs that form-engine sequence in one step. Runs repeats validation, computation, or the complete form flow against the same prepared interpreter and Document source; one run reports elapsed time and multiple runs report p95.

  5. Choose the validation scope

    Full validates the complete Document. Partial validates only the model-defined effects of the path and coordinates shown beside the operation buttons. Results and failures appear as structured JSON.

  6. Local file handling

    Nothing is uploaded. The page reads selected models and Documents locally in the browser and does not store user-selected files in its offline cache.
